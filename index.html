Sauvegarde automatique

À chaque modification, une copie de ton budget est envoyée dans ton dépôt GitHub privé ecureuil-sauvegarde. Si ce téléphone perd ses données, colle à nouveau ta clé ici pour tout récupérer.

Comment créer la clé ?
  1. Sur github.com : ta photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Écureuil ». Expiration : la plus longue possible.
  3. Repository access → Only select repositories → ecureuil-sauvegarde.
  4. Permissions → Contents → Read and write.
  5. Generate token, copie-la, colle-la ici, et garde-la aussi dans tes notes ou tes mots de passe.
